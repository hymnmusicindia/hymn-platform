# HYMN material system

The purple accent layer has been replaced by app/styles/material-depth.css.
Graphite, porcelain and brushed silver preserve the monochrome logo identity.
Cool blue-grey and warm mineral tones add depth through surface gradients.

Shared cards have lit edges and contact shadows; inputs are recessed; primary
buttons and the current navigation page have raised bevels. Status colours retain
their existing meaning. Large editorial text uses a subtle metallic gradient;
body text stays solid. Reduced-motion and forced-colour fallbacks are included.

Desktop navigation is a recessed rail with a raised current-page pill. Mobile
links share the selected-page treatment. Both expose aria-current and keyboard focus.

Store tracks have transparent surfaces and edge masks, with no section rules or
separate background panels. The surrounding atmospheric wash fades to transparent.

Validation: TypeScript, CSS parsing and isolated light/dark material previews.
Every live route has not been browser-verified; bespoke components may retain
their own treatments.
